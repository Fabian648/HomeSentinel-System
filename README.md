# HomeSentinel-System

Ein IoT-Demo-System mit Java, Spring Boot, Redis und Docker.

## Architektur
- **Backend**: Spring Boot Service mit Redis-Anbindung.
- **Simulator**: Java-App, die Temperatursensoren simuliert.
- **Redis**: In-Memory DB für Telemetriedaten.

## Starten
Einfach im Hauptverzeichnis ausführen:
```bash
make run-system
```
